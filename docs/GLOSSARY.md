# GLOSSARY — термины домена «Ноутбук-пианино»

Единственный источник терминов. Тикеты, код, UI — без синонимов.

## Термины

### Клавиши

| Термин | Значение |
|--------|----------|
| **Физическая клавиша** | Клавиша клавиатуры ноутбука. Идентифицируется `KeyboardEvent.code` (напр. `KeyA`), НЕ `event.key`. |
| **Экранная клавиша** | Нарисованная на экране фортепианная клавиша (белая/чёрная). Носит подпись физической клавиши. Единственный носитель подсветки — физическую подсветку MacBook API не позволяет. |
| **Подсветка** | Визуальное выделение экранных клавиш, которые требуется нажать. |
| **Маппинг** | Соответствие «физическая клавиша ↔ нота» на данный момент. База (ADR-006 v3): `Tab Q W E R T Y U I O P [ ] \` + `B N M , . / Shift(правый)` = белые C4–B6 (3 полные октавы; Tab = C4 по решению игрока — фокус-навигация отключена), `1 2 4 5 6 8 9 − = Del(⌫)` + `H J L ; '` = чёрные. Backquote и ShiftLeft — не ноты (Backquote освобождён, левый Shift — свободный модификатор). Ноты вне охвата не отображаются. |
| **Октавный сдвиг** | Смещение маппинга на октаву: `Z` — вниз, `X` — вверх. |

### Ноты и время

| Термин | Значение |
|--------|----------|
| **Нота** | Тройка (питч, момент, длительность) в сетке мелодии. Каноничное представление — MIDI note number 0–127. |
| **Питч** | Высота звука. C4 = MIDI 60. |
| **Имя ноты** | Западная запись: буква + октава, напр. `C4`. Основная нотация приложения. |
| **Русское имя ноты (сольфеджио)** | Запись ступенью: до, ре, ми, фа, соль, ля, си (с ♯ для чёрных). Показывается рядом с именем ноты в скобках: `B4 (си)`. Полная форма для объяснений: «си первой октавы» (C4–B4 = первая октава, C5–B5 = вторая, C3–B3 = малая). |
| **Темп (BPM)** | Скорость мелодии, записанная в файле. Свойство композиции. |
| **Множитель скорости** | Коэффициент замедления воспроизведения 0.25–1.0. Не менять BPM файла — играть медленнее. |
| **Аудио-часы** | `AudioContext.currentTime` — единственный источник истины о времени во время игры. Не `Date.now()`, не `performance.now()`. |
| **Линия удара** | Горизонталь у клавиатуры, где нота должна быть нажата. |
| **Колонка нот** | Вертикальный коридор над экранной клавишей, по которому падают её ноты. |
| **Окно попадания** | Допуск ±мс вокруг момента ноты, внутри которого нажатие засчитывается. |
| **Попадание** | Нажатие физической клавиши внутри окна попадания. |

### Партии и файлы

| Термин | Значение |
|--------|----------|
| **MIDI-трек** | Дорожка внутри MIDI-файла (техническая единица файла). |
| **Партия руки** | Правая / левая рука, результат разбора MIDI-треков. Красится своим цветом. |
| **Режим партии** | `обе` / `только правая` / `только левая`. Ненажимаемая партия — автопартия: звучит, подсвечивается, не требует нажатий. |
| **Библиотека** | Встроенные мелодии + загруженные пользователем файлы. |

### Исполнение

| Термин | Значение |
|--------|----------|
| **Wait-mode** | Воспроизведение стоит, пока не нажата следующая ожидаемая клавиша. |
| **Автоплей** | Режим «бунрежим»: мелодию целиком играет компьютер, подсветка показывает, что он «жмёт». |
| **Полифония** | Одновременное звучание нескольких нот (аккорды). |
| **Пресет (тембр)** | Инструмент звучания: «Фортепиано», «Орган», «Синт-лид», ... |
| **Счёт прохождения** | Итог прохода мелодии: % попаданий, стрик, ошибки. |

### Азбука (обучение нотной грамоте)

| Термин | Значение |
|--------|----------|
| **Азбука** | Отдельный раздел обучения нотной грамоте (⌥A): уроки-карточки. |
| **Нотный стан** | Пять параллельных линий, на/между которыми записываются ноты. |
| **Скрипичный ключ** | Ключ 𝄞: вторая линия стана = G4. В v1 азбуки единственный. |
| **Позиция на стане** | Место ноты: линия или промежуток; добавочные линейки ниже/выше стана. |
| **Головка ноты** | Овал ноты; заполненная (четверть/восьмая) или пустая (целая/половинная). |
| **Штиль** | Вертикальная палочка у головки (у четверти и короче). |
| **Флаг / рёбра** | Хвостик восьмой; пары восьмидольных соединяются ребром. |
| **Длительность** | Временнóе значение ноты: целая, половинная, четверть, восьмая. |
| **Пауза** | Знак молчания той же длительности, что и нота. |
| **Такт** | Отрезок между тактовыми чертами; размер 4/4 или 3/4 задаёт его наполнение. |
| **Размер** | Дробь при ключе: числитель — доли, знаменатель — длительность доли. |
| **Урок** | Серия карточек одного навыка; следующий открывается при ≥80% правильных. |
| **Карточка** | Одно упражнение: вопрос (нота на стане / длительность / такт) + ответ клавишей или выбором. |
| **Ответ клавишей** | Сыграть asked-ноту на игровой клавиатуре (мостик к основному режиму). |
| **Нотная тетрадь** | Режим практики в Азбуке: сгенерированная последовательность тактов на стане, игрок играет её подряд с листа (PIANO-12, SPEC §4.10). |
| **Чтение с листа** | Непрерывная игра по записи без остановки на вопрос-ответ; время не лимитировано — тетрадь стоит на текущей ноте до верного нажатия. |
| **Текущая нота тетради** | Нота, которую ждёт судья; подсвечена на стане; остальные — серым (ink приглушён). |
| **Уровень тетради** | Диапазон и ритмическая сложность генерации (4 уровня: первая октава → обе, четверти → +длительности). |
| **Попытка ноты** | Нажатия до верного; «верно с первой» — попадание без промаха на этой ноте. |
| **Диктант** | Режим тренировки слуха в Азбуке (PIANO-17): Азбука играет последовательность нот, игрок повторяет её нажатиями клавиш, проверка — по завершении ввода или кнопкой «Проверить». |
| **Позиция диктанта** | Место ноты в последовательности диктанта; проверка считает % верных позиций. |
| **Разбор диктанта** | Вердикт по каждой позиции: какая нота ожидалась, какая сыграна (имя ноты + русское имя). |
| **Уровень диктанта** | Длина и диапазон генерации (4 уровня: 2 ноты белых C4–C5 → 5 нот с диезами; шаг ≤ квинты, первая C4/E4/G4). |

### Гитара (раздел Азбуки, research 06)

| Термин | Значение |
|--------|----------|
| **Раздел «Гитара»** | Секция Азбуки: уроки Г1–Г6 (своя последовательность и гейты, прогресс `guitar-1..6`), чтение нот для гитары с I позиции. |
| **Гриф** | Доска гитары с ладами. Диаграмма грифа на карточке — подсказка «струна.лад»; ввода не принимает и ничего не судит (третий слой «стан ↔ роя ↔ гриф»). |
| **Струна (номер)** | 1 = верхняя тонкая (высокая E) … 6 = нижняя толстая (низкая E). Строй EADGBE: открытые звучат MIDI 64, 59, 55, 50, 45, 40 (1-я → 6-я). |
| **Лад** | Поперечная полоса (порожек) на грифе; прижим струны у лада меняет её высоту на полтона за лад. Внутри I позиции — лады I–IV, подпись на диаграмме — цифрой («0»–«4», таб-конвенция). |
| **Открытая струна** | Струна без прижатия (лад 0). Запись открытых по порядку струн: E5, B4, G4, D4, A3, E3. |
| **Позиция (I)** | Позиция = лад, где стоит 1-й палец; I позиция = лады 0–4. Записанный диапазон E3–G♯5 (MIDI 52–80, все 29 высот достижимы). |
| **Записанная высота** | Питч на стане и ответ роя — канон приложения (GLOSSARY «Питч»). Вопрос и ответ гитарных уроков — всегда записанная высота. |
| **Гитарная тетрадь** | Режим практики секции «Гитара» (PIANO-20): та же механика нотной тетради (8 тактов 4/4, чтение с листа), но пул — записанные высоты I позиции (4 уровня: открытые струны → струны 1–2 → натуральные → все 29 с диезами). Подсказка на выбор: «Клавиатура» («жми-сейчас»), «Гриф» (диаграмма «струна.лад» текущей ноты), «Нет» (чистое чтение). Прогресс `guitar-notebook-level-N`. |
| **Звучащая высота** | Реальный звук гитары: записанная − 12 — гитара звучит октавой ниже записи; маленькую «8» под скрипичным ключом обычно не пишут. Звук показа карточек гитарных уроков. |
| **Дубликат B4** | Единственная нота I позиции с двумя местами: открытая 2-я и 3-я струна IV лад. Конвенция школ — открытая 2-я (словарь приложения); в уроке 3-й струны диаграмма показывает 3.IV по явной подсказке карточки. |
| **Нота словаря I позиции** | Пара «струна.лад» из словаря `writtenToGuitar` (src/core/fretboard.ts); единственный источник соответствия «записанная высота ↔ гриф». |

## Avoid-список (запрещённые синонимы)

| ❌ Не говорить | ✅ Говорить |
|----------------|------------|
| «кнопка» для клавиши пианино/клавиатуры | **клавиша** («кнопка» = только UI-элементы) |
| «дорожка» без уточнения | **MIDI-трек**, **партия руки** или **колонка нот** — три разные вещи |
| «скорость» вместо темпа | **множитель скорости** или **темп (BPM)** — разные вещи |
| «звук» при выборе инструмента | **пресет (тембр)**; «звук» — только про физику звучания |
| «подсветка клавиатуры ноутбука» | **подсветка экранных клавиш** — физическая невозможна (см. ADR-001) |
| «заметка» для note | **нота** |
| «нижняя/первая поперёк» про струны гитары | **1-я — верхняя тонкая, 6-я — нижняя толстая** (номер = сверху вниз) |
| «порожек» про место прижатия | **лад** (порожек — сама полоса-металл, лад — место на грифе) |

## Инварианты

1. **Маппинг резолвится по `event.code`** — работает при любой раскладке ОС (русская/английская).
2. **Время — только аудио-часы.** Планирование нот и визуализация синхронизированы с `AudioContext.currentTime`.
3. **Связка «нота ↔ экранная клавиша ↔ физическая клавиша»** всегда вычисляется через текущий октавный сдвиг, одно место в коде.
4. **Нота вне маппинга** (вне C4–B6 при текущем сдвиге) — на поле нот не отображается (ADR-006 п.6), озвучивается автопартией, но неиграема с клавиатуры; текущий диапазон показывает HUD.
5. **Подсветка в wait-mode** = следующая ожидаемая нота (или аккорд); в обычном режиме = ноты в окне попадания.
