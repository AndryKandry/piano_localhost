# Ноутбук-пианино

Веб-приложение: клавиатура ноутбука превращается в фортепиано. Учись играть по
падающим нотам с подсветкой клавиш (как табы в гитаре, только для пианино),
загружай свои мелодии из MIDI/MusicXML, слушай автопроигрывание, меняй тембр.

## Возможности

- **Свободная игра** — полифония, педаль на Space, сдвиг октавы Z/X
- **Обучение** — падающие ноты (Synthesia-стиль), две партии рук цветами,
  wait-mode (мелодия ждёт правильного нажатия), множитель скорости 0.25–1.0,
  счёт прохождения (% попаданий, стрик, разбор ошибок)
- **Автопроигрывание** — «бунрежим»: компьютер играет сам, подсветка показывает,
  что он «жмёт»; выбор партии (обе / правая / левая — вторую играет автопартия)
- **Библиотека** — 11 встроенных мелодий public domain (Бах, Бетховен, Моцарт,
  Вивальди, Григ, народные) + загрузка своих `.mid` и `.musicxml` файлов
  (кнопкой или drag&drop), ручной порог разбора партий рук
- **Тембры** — Фортепиано (сэмплы Splendid Grand Piano), Орган, Синт-лид, Бас;
  смена на ходу
- **Азбука** (⌥A) — уроки нотной грамоты на нотном стане: скрипичный ключ,
  ноты первой/второй октавы, длительности, паузы, такты и размеры; ответ
  клавишей пианино или выбором, прогресс и последовательность уроков —
  в браузере (следующий урок открывается при ≥80%)
- **Отсчёт 5-4-3-2-1** перед стартом мелодии — время приготовиться
- **Офлайн** — service worker: после первой загрузки работает без сети
  (сэмплы — из кэша браузера после первого звучания)
- Русский интерфейс, настройки и прогресс — в браузере, без аккаунтов

## Раскладка клавиш

2 полные октавы C4–B5, хроматический ряд (как Virtual Piano):

```
  1 2   4 5 6   8 9   − = Del     ← чёрные (3 и 7 пропущены — там их нет)
Tab Q W E R T Y U I O P [ ] \     ← белые (C4 … B5)
```

На экранной клавиатуре каждая нота подписана дважды — западное имя и русская
ступень: `C4 (до)`, `C♯4 (до♯)`.

| Действие | Клавиши |
|----------|---------|
| Ноты | `Tab Q W E …` белые, `1 2 4 5 6 8 9 − = ⌫` чёрные |
| Октава вниз/вверх | `Z` / `X` |
| Педаль (sustain) | `Space` |
| Wait-mode | `⌥W` (Option+W) |
| Партия руки | `⌥H` |
| Режим (свободная/обучение/автоплей) | `⌥M` |
| Панель | `⌥P` или кнопка «☰ Панель» |
| Азбука (нотная грамота) | `⌥A` или кнопка в панели |
| Множитель скорости | `↑` / `↓` |

Звук включается браузером только после первого клика по странице
(autoplay-политика; приложение честно показывает подсказку).

## Запуск

```bash
npm install
npm run dev        # разработка (vite)
npm run build      # сборка в dist/
npm run preview    # «прод»: собранное на http://localhost:4173
```

Проверки логики (без браузера):

```bash
npm run smoke:mapping   # 218 ассертов: таблица нот, сдвиги, клампы
npm run smoke:import    # 189: MIDI/MusicXML парсеры, библиотека
npm run smoke:player    # 67: судья, wait-mode, планировщик, партии
npm run smoke:ui        # 53: настройки, сплит партий
npm run smoke:notation  # геометрия нотного стана азбуки
npm run smoke:primer    # движок уроков азбуки, прогресс, блокировка до 80%
```

## Структура

```
src/
  core/      типы, аудио-часы, маппинг клавиш, геометрия клавиатуры, настройки
  audio/     движок (голоса, педаль), сэмплы (smplr), синтезаторные пресеты
  input/     клавиатурный ввод (event.code — любая раскладка ОС)
  import/    MIDI (@tonejs/midi) и MusicXML (свой DOMParser-экстрактор)
  library/   встроенные мелодии, IndexedDB-хранилище, ручной сплит партий
  player/    машина состояний, lookahead-планировщик, судья попаданий
  render/    канвасы: экранные клавиши + поле падающих нот (Canvas 2D)
  notation/  рендер нотного стана (Canvas 2D + шрифт Bravura) для «Азбуки»
  primer/    «Азбука»: уроки-карточки, движок урока, прогресс, экран
  ui/        DOM-панели: библиотека, транспорт, диалоги, экран итогов
docs/        глоссарий, ADR, research-доки и спека (domain-first процесс)
```

Архитектурные решения зафиксированы в `docs/adr/`:
экранная подсветка вместо физической (macOS не даёт адресную), голый Web Audio
+ smplr, время — только аудио-часы, позиция нот — чистая функция времени,
Canvas 2D в два слоя.

## Атрибуция

- **Splendid Grand Piano** — сэмплы фортепиано, public domain (через
  библиотеку [smplr](https://github.com/danigb/smplr))
- **Bravura** — нотный шрифт SMuFL для «Азбуки»,
  [SIL Open Font License 1.1](https://github.com/steinbergmedia/bravura/blob/master/LICENSE.txt)
  (через пакет [@fontsource/bravura](https://github.com/fontsource/fontsource))
- [@tonejs/midi](https://github.com/Tonejs/Tone.js) — разбор MIDI-файлов
- Встроенные мелодии — public domain аранжировки

## Заметка про «а почему localhost»

Приложение полностью клиентское — сервер только отдаёт файлы: ES-модули и
service worker не работают с `file://`. Варианты без сервера: установить как
PWA (Chrome «Установить приложение» / Safari «Добавить в Dock») — дальше
работает из кэша; либо собрать single-file HTML.
