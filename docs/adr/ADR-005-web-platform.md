# ADR-005: Платформа — веб-приложение (браузер)

Статус: принято (2026-11-23)

## Контекст

MacBook — целевое устройство. Выбрано в grilling. Альтернативы: desktop
(Tauri) или native macOS (Swift).

## Решение

Веб-приложение: статический фронтенд, открывается в браузере, опционально
PWA позже (офлайн + ярлык в Dock). Без серверной части, без аккаунтов —
прогресс в localStorage.

Обоснование:
- Web Audio API даёт нужную задержку на macOS (research 01);
- клавиатурный ввод и Canvas — полностью покрыты браузером (research 03, 04);
- нативные бонусы macOS не нужны: физ. подсветка невозможна в любом случае
  (ADR-001);
- скорость итераций и нулевая установка.

## Альтернативы

| Альтернатива | Почему нет |
|--------------|------------|
| Tauri desktop | Те же web-технологии внутри + вес сборки; оффлайн решается PWA |
| Native Swift | Лучший контроль звука, но дольше разработка, только macOS, а критичных нативных возможностей нет |

## Последствия

- Требование: работать офлайн после первой загрузки (сэмплы и библиотека
  кэшируются) — учесть в спеке.
- Браузерные ограничения приняты: Cmd-комбинации не перехватываются,
  window blur → all-notes-off (research 03).
