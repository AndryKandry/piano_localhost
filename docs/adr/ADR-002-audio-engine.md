# ADR-002: Звук — голый Web Audio API + smplr, сэмплы Salamander; без Tone.js

Статус: принято (2026-11-23)

## Контекст

Нужны: отклик < 30–40 мс от нажатия до звука, полифония, реалистичное
фортепиано + синтезаторные пресеты, автоплей с точным планированием,
wait-mode, sustain-педаль на пробел.

Research (`docs/research/01-audio-engine.md`).

## Решение

1. **Ядро — голый Web Audio API**: `AudioContext({latencyHint:'interactive'})`,
   `decodeAudioData` при загрузке. На macOS типично ~5–15 мс baseLatency —
   бюджет выполняется.
2. **Планировщик автоплея/автопартии** — lookahead-паттерн «A Tale of Two
   Clocks» (Chris Wilson): тик ~25 мс, планирование на аудио-часах на ~100 мс
   вперёд. Wait-mode играет по нажатию — без lookahead.
3. **Сэмплы фортепиано**: Splendid Grand Piano (public domain) через smplr —
   нарезка с CDN smplr. Salamander (CC-BY-3.0) отвергнут на практике:
   в smplr отсутствует (закрыл открытый пункт research 01).
4. **Загрузчик сэмплов**: smplr — `start/stop(note)` с фейдом, per-note gain.
5. **Синтезаторные пресеты** — свои голоса на осцилляторах (осц + фильтр +
   ADSR), десятки строк кода, без библиотек.
6. **Note-off**: не обрывать сэмпл, гейтить GainNode-рампой; педаль Space —
   буфер hold-нот с release при отпускании.

## Альтернативы

| Альтернатива | Почему нет |
|--------------|------------|
| Tone.js | Transport прячет аудио-часы и конфликтует с wait-mode; PolySynth не нужен; сотни КБ лишнего веса |
| soundfont-player | Общая SoundFont-механика, лицензии пакетов не подтверждены; smplr покрывает |
| Полный SF2-движок | Несоразмерный вес/сложность для 1 фортепиано + пресетов |

## Последствия

- Аудио-часы `AudioContext.currentTime` — единственный источник времени всего
  приложения (инвариант GLOSSARY #2): рендер и планирование читают его.
- Зависимости аудио-слоя минимальны: smplr + сэмплы. Свои пресеты — наш код,
  наше API.
- Атрибуция сэмплов в UI (Splendid — public domain, атрибуция — жест
  вежливости).
- Точные мс задержки подтвердить замером на целевом MacBook в прототипе
  (research не подтверждает цифры официально).
