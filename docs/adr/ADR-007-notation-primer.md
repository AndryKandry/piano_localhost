# ADR-007: Азбука — обучение нотной грамоте на своём Canvas-рендере + шрифт Bravura

Статус: принято (2026-11-23)

## Контекст

Новый раздел «Азбука» (⌥A): уроки-карточки нотной грамоты — скрипичный ключ,
ноты первой/второй октавы на стане, длительности (целая/половинная/четверть/
восьмая) и паузы, такты и размеры 4/4, 3/4. Ответ игрока — клавишей пианино
или выбором. Уроки последовательные: следующий открывается при ≥80%.

Research (`docs/research/05-notation-rendering.md`).

## Решение

1. **Рендер — свой лёгкий Canvas 2D + шрифт Bravura (SMuFL)**:
   - `@fontsource/bravura` (woff2 ~316 КБ, SIL OFL 1.1), загрузка через
     FontFace API, `ctx.font = '<em>px Bravura'`; размер шрифта = высота
     стана (1 пробел = 0.25 em — из спеки SMuFL).
   - Глифы по кодпоинтам спеки: ключ U+E050, головки U+E0A2/E0A3/E0A4,
     паузы U+E4E3–E4E6, тактовая черта U+E030, размер U+E083/E084,
     флаг восьмой U+E240, (на будущее: ♯♭♮ U+E262/E260/E261).
   - Штили рисуем линией (длина 3.5 пробела — практика Gould/MuseScore,
     спекой не фиксируется), толщины — из Bravura.json.
2. **VexFlow отвергнут**: 761 КБ gzip (глифы запечены в JS) для карточек из
   1–3 нот несоразмерно; OSMD отвергнут ранее (ADR-003).
3. **Юникод-блок U+1D1xx без спецшрифта не используем** — системная поддержка
   ненадёжна (tofu-фолбэк), поведения на macOS-браузерах не подтверждено.
4. **Структура урока**: конечный автомат карточек (вопрос → ответ →
   обратная связь → следующая); ответ клавишей = играть ноту на игровой
   клавиатуре (мостик к основному режиму), ответ выбором = кнопки.
5. **Прогресс**: localStorage, уроки последовательные (≥80% правильных
   открывает следующий), на карточке урока лучший результат.
6. **Вход**: ⌥A или кнопка в панели; отдельный полноэкранный экран со своим
   канвасом, основная игра не меняется.

## Альтернативы

| Альтернатива | Почему нет |
|--------------|------------|
| VexFlow | 761 КБ gzip; API для нотных листов, подсветка отдельных нот карточек — через боль |
| OSMD | Надстройка над VexFlow, 1.4 МБ (усиливает ADR-003) |
| Юникод-символы системными шрифтами | Tofi/фолбэк-риски, контроль отсутствует |
| DOM+CSS вместо канваса | Позиционирование нот на стане — сетка в em; канвас уже инфраструктура проекта (ADR-004) |

## Последствия

- +316 КБ лениво (шрифт грузится при первом входе в Азбуку, не на старте).
- Зависимость от одного шрифта с открытой лицензией; замена — любой SMuFL-шрифт.
- Карточный движок переиспользуем для будущих уроков (басовый ключ,
  альтерация — v2: бэклог).
- Атрибуция Bravura (SIL OFL) в README.
